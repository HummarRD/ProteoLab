# ProteoLab

Simulador didáctico interactivo del flujo de **proteómica basada en electroforesis bidimensional (2D-PAGE)**, construido sobre el protocolo de:

> Choi JE, Lee JJ, Kang W, Kim HJ, Cho JH, Han PL, Lee KJ. Proteomic analysis of hippocampus in a mouse model of depression reveals neuroprotective function of ubiquitin C-terminal hydrolase L1 (UCH-L1) via stress-induced cysteine oxidative modifications. *Mol Cell Proteomics*. 2018;17(9):1803–1823. https://doi.org/10.1074/mcp.RA118.000835

**Abrir el simulador:** https://hummarrd.github.io/ProteoLab/

## Módulos
1. Modelo de estrés crónico por restricción y obtención del hipocampo
2. Lisis, cuantificación por BCA y precipitación
3. Electroforesis bidimensional (IEF pH 4–7 + SDS-PAGE, tinción con plata)
4. Análisis de imagen y selección de spots (datos de la Tabla I)
5. Digestión en gel y nanoLC-MS/MS (top-10)
6. Búsqueda en base de datos (iones b/y, score) y validación con mutantes de Cys

Cada módulo tiene modo **guiado**, **exploración**, **evaluación** y **proyección** para el aula.
